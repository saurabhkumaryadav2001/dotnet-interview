# C# Design Patterns — Interview & Practical Learning

A project-based guide to classic GoF and enterprise design patterns using C# and .NET.

## Learning approach

Every pattern includes:
- Problem it solves
- Before/after design
- Runnable C# example
- Real-world .NET use case
- Interview-ready explanation
- Trade-offs and practice questions

## Interview framework

For each pattern, answer in this order:

1. **Problem:** What design problem occurs?
2. **Solution:** What is the core idea?
3. **Structure:** Which interfaces/classes collaborate?
4. **Example:** Where have you used it or where would you use it?
5. **Trade-off:** What complexity does it introduce?
